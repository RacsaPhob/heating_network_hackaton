# Проверки стартового проекта — архив

Актуальные результаты локальной проверки и ограничения: `docs/COMPLIANCE.md`. Ниже сохранён ранний протокол.

Проверено 17 сентября 2026 года.

## Выполнено

- Извлечение справочников из DOCX: 18 диаметров с пропускной способностью, длиной, ценами и габаритами; 4 диапазона стоимости камер; обязательные поля 7 выходных типов.
- Аудит исходного GeoJSON: 144 объекта, 9 групп расхождений; входной файл не изменяется. Отчёт `dataset-audit.json` содержит SHA-256 исходного файла.
- Восемь тестов диагностического инструмента: явно заданный нулевой расход, отсутствующий расход, цикл upstream, несуществующая ссылка, коллизия ID, неизвестное ограничение, неизменность входа и диагностика переданного файла.
- Синтаксическая проверка Maven POM как XML и структуры JSON справочника.
- Проверка Compose-конфигурации установленным Docker Compose v2 с явным именем проекта `heatnet`. Это не запуск контейнеров и не проверка требуемой версии 1.29.2.

## Ещё не выполнено

- `mvn test` и полная сборка Java-приложения: Maven не найден, установленная Java — 8, требуется 11.
- Запуск контейнеров: Docker Engine выключен. Наличие Dockerfile не подтверждает успешную загрузку образов/зависимостей и сборку.
- Развёртывание на Ubuntu Server 22 / docker-compose 1.29.2.
- Работа с PostgreSQL из приложения, загрузка через API, маршрутизация, инженерный расчёт и экспорт: эти функции ещё не реализованы.
- Импорт 3 ГБ, экспорт 500 МБ и нагрузка 50 пользователей: настройки multipart не заменяют реализацию и нагрузочное испытание.

Тест MetadataController подготовлен для проверки включения справочника в classpath и честного объявления возможностей, но не запускался в этом окружении.
