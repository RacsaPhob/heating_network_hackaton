# Сверка решения с ТЗ и разъяснениями организаторов

Дата проверки: 25.09.2026. Источники: `2. ДИТ.pdf`, `Техническое приложение ЛЦТ.docx`, `Разъяснения по вопросам ЛЦТ.docx` из папки ТЗ пользователя и скорректированный GeoJSON. Разъяснения и новое техническое приложение применены к конфликтующим пунктам исходного документа.

| Пункт | Состояние | Проверка / ограничение |
|---|---|---|
| Приём и разбор GeoJSON | Частично | Скорректированный набор 633 402 байта, 144 объекта, 17 точек загружен успешно. Лимит приложения — 20 МБ, 4000 объектов, 100 точек; требование 3 ГБ не выполнено. |
| Цель для каждой `oks_connection_point` | Выполнено для примера | Каждая точка учитывается отдельно; 12 подключены первым вариантом, 5 отмечены неподключёнными. |
| Сохранение числовых ID и ссылок | Выполнено для экспорта | Проверены типы `source_object_id` и `connected_object_ids` в выходном GeoJSON. |
| Без реконструкции существующей сети | Выполнено | Выход строится только из новых участков, камер, технических узлов и сводки. |
| До трёх вариантов и сравнение | Частично | Три варианта строятся и отображаются; два имеют нарушения и требуют доработки. |
| Ограничения трассы и спецпереходы | Частично | Базовые проверки работают, но специальные переходы и все пространственные ограничения не покрыты; независимой полной геометрической экспертизы нет. |
| Расчёт диаметров и непрерывной длины | Частично | Подбор и проверка присутствуют; на двух расширенных вариантах выявлено превышение длины ДУ100. |
| Формула стоимости и оценки | Выполнено для экспорта | Проверены арифметика стоимости, штрафов и `0.7*(cost/25 млн)+0.3*(length/100)`. Пять неподключённых точек дают штраф. |
| Выходной GeoJSON | Выполнено для первого варианта | Проверены четыре допустимых типа, обязательные поля, ссылки, концы геометрий и одна `variant_summary`. Размер экспортированного примера 13 958 байт. |
| CSV-отчёт, карта, поиск, история | Реализовано | Доступно в интерфейсе; проверен API экспорта. |
| PostgreSQL / Docker | Проверено локально | Docker Compose собрал Java 11/Spring Boot 2.6.3 и запустил сервис с PostgreSQL. Ubuntu Server 22 и Compose 1.29.2 отдельно не проверялись. |
| 500 МБ экспорт, 50 пользователей | Не подтверждено | Нагрузочных и больших файловых испытаний не было. |

Первый вариант является демонстрацией работающего пайплайна, а не доказательством полного решения конкурсной задачи. Обозначение `checks_passed=true` означает лишь, что реализованные проверки не нашли нарушений.

Приоритеты до технической приёмки: (1) полноценные обходы препятствий и специальные переходы; (2) устранение пяти неподключённых точек без нарушений; (3) потоковая обработка/экспорт больших файлов; (4) испытания на 50 пользователях и целевой Ubuntu/Compose; (5) независимая пространственная проверка результата.
