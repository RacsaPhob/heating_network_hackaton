# Материалы HackageCrew для загрузки решения

## Состав пакета

Для передачи всех материалов одним файлом используется `HackageCrew_полный_пакет.zip`. Те же файлы доступны отдельно; контрольные суммы — в `HackageCrew_контрольные_суммы.sha256`.

1. `HackageCrew_ЛЦТ_по_шаблону.pdf` — 11 слайдов для отдельной публичной ссылки в поле «Презентация». PDF хранится отдельно от Git-репозитория. Обязательные слайды 7–11 сохраняют геометрию исходного шаблона; на слайде с составом команды удалена только лишняя пятая карточка. `HackageCrew_ЛЦТ_по_шаблону.pptx` — редактируемый исходник. Команда: Самир Исламгулов (тимлид и интеграция), Аскар Султанов (алгоритм и backend), Дамир Зарипов (геоданные и ограничения), Артём Чернышёв (инженерные расчёты и тестирование). Все — УУНиТ, Уфа.
2. `HackageCrew_исходники.zip` — исходный код, исправленный конкурсный набор и документация. ZIP создаётся без `.git`, пользовательских данных и сборочных файлов.
3. `HackageCrew_ЗИЛ_результат.geojson` — экспорт первого варианта на скорректированном наборе.
4. `HackageCrew_ЗИЛ_сравнение.csv` — табличная сводка расчёта.
5. `HackageCrew_проверка_ТЗ.md` — развёрнутая матрица соответствия и известные ограничения.

Исходный исправленный набор: 633 402 байта; SHA-256 `CFFB7133419D93FE364A53015A7D3EAD289F671CBFAF6F4BEFE87F2A21914130`.

## Как запустить для жюри

```sh
docker compose -p heatnet-hackagecrew up -d --build
```

Открыть `http://127.0.0.1:8080/`, нажать «Открыть конкурсный набор» → оставить «Демонстрационный» → «Построить варианты». Первый вариант проходит реализованные проверки, но подключает 12 из 17 точек. Два других подключают 14, но помечены нарушениями; их нельзя представлять как корректное решение. Затем показать таблицу сравнения, неподключённые точки и экспорт.
